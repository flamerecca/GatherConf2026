# 會員任務頁 `/member/tasks`

本文件說明會員任務與胡蘿蔔頁面的版面與行為，對象為維護頁面的工程與營運人員。英文版路徑為 `/en/member/tasks`，需登入並已驗證 Email 才能進入。

---

## 1. 頁面結構

由上到下：

1. 頁首標題「任務與胡蘿蔔」。
2. 「← 會員頁面」按鈕，回到會員中心。
3. 目前的胡蘿蔔餘額，餘額為負數時以紅色粗體顯示。
4. 「輸入授權碼」表單，見第 5 節。
5. 站上任務，分成「帳號任務」與「人格測驗與好友任務」兩組，標題都可以收合。
6. 年會現場任務，只列出目前開放的任務，任務代碼不會顯示在頁面上。

---

## 2. 頁首的「會員頁面」按鈕

- 位置在標題下方、餘額上方。
- 中文顯示「← 會員頁面」，英文顯示「← Member page」。
- 連到會員中心，中文是 `/member`，英文是 `/en/member`。
- 樣式為外框按鈕，和下方實心的「前往完成」按鈕區隔，避免兩者搶視覺權重。
- 文字定義在 `lang/zh_TW/carrots.php` 與 `lang/en/carrots.php` 的 `list.member_page`。

---

## 3. 站上任務的「前往完成」按鈕

每個尚未完成的站上任務，下方會有一個「前往完成」按鈕，英文版顯示「Go do it」，點擊後導向可以完成該任務的頁面：

| 任務 | 獎勵 | 導向 |
| :--- | :--- | :--- |
| 驗證 Email | 5 | 沒有按鈕，從註冊或登入信件中完成 |
| 設定密碼 | 3 | `/member/password` |
| 完成人格測驗 | 5 | `/quiz` |
| 交到第一位好友 | 5 | `/friends` |
| 傳出第一則訊息 | 2 | `/friends` |

- 英文版導向對應的 `/en/...` 頁面。
- 「傳出第一則訊息」導向好友頁，因為訊息只能傳給好友，也沒有獨立的訊息列表頁，使用者要在好友頁挑一位好友開啟對話。
- 已完成的任務不顯示按鈕，狀態標示為「已完成」。
- 獎勵點數定義在 `config/carrots.php` 的 `site`。
- 任務與導向頁面的對照寫在 `resources/views/member/tasks.blade.php` 的 `$siteTaskRoutes`。

---

## 4. 新增或調整站上任務

1. 在 `config/carrots.php` 的 `site` 加入任務代碼與獎勵點數。
2. 在 `lang/zh_TW/carrots.php` 與 `lang/en/carrots.php` 的 `site` 加入該任務的 `name` 與 `description`。
3. 在 `resources/views/member/tasks.blade.php` 的 `$groups` 把代碼放進對應的群組。
4. 需要導向按鈕時，在同一個檔案的 `$siteTaskRoutes` 加入代碼與路由名稱，不含 `.en` 後綴，英文版會自動補上。
5. 在 `tests/Feature/Carrots/TaskListTest.php` 補上對應的斷言。

---

## 5. 輸入授權碼

任務頁的「輸入授權碼」表單，英文版是「Enter an access code」，會員輸入一組碼就能換取胡蘿蔔，送出到 `POST /member/tasks/redeem`。

### 兩種碼

| 種類 | 用途 | 規則 |
| :--- | :--- | :--- |
| 授權碼 | 後台「授權碼」資源建立，用於活動發放、合作夥伴或贈送 | 每組有獎勵數量、可兌換次數上限、啟用開關與開始、結束時間，每位會員同一組只能兌換一次 |
| 現場任務短碼 | 每個現場任務自動產生，等於不掃 QR Code 也能完成任務 | 沿用該任務原本的獎勵、開放時間與每人一次的規則 |

- 系統先比對現場任務短碼，再比對授權碼，兩種碼不會重複。
- 碼為 8 碼大寫英數字，不含容易混淆的 `0`、`O`、`1`、`I`。
- 輸入不分大小寫，空格與連字號會被忽略，所以 `abcd-1234` 等於 `ABCD1234`。

### 結果與訊息

| 情況 | 會員看到的訊息 |
| :--- | :--- |
| 兌換成功 | 兌換成功，獲得 N 根胡蘿蔔，並回到任務頁 |
| 找不到這組碼 | 找不到這組授權碼，請確認後再試一次 |
| 已經用過 | 你已經使用過這組授權碼了 |
| 不在開放期間或已停用 | 這組授權碼目前不在可使用的期間內 |
| 兌換次數已滿 | 這組授權碼已經被兌換完了 |
| 錯誤次數太多 | 輸入錯誤的次數太多，請 N 分鐘後再試 |

文字定義在 `lang/zh_TW/carrots.php` 與 `lang/en/carrots.php` 的 `code`。

### 防暴力猜測

- 每位會員每分鐘最多送出 10 次，限流名稱為 `member-code`，定義在 `AppServiceProvider`。
- 輸入找不到的碼累計 5 次，會鎖定 10 分鐘，鎖定期間連正確的碼也不能使用。
- 碼本身存在，只是已用過、已過期或已兌換完，不算錯誤次數。

### 記帳

- 兌換紀錄的原因是 `code`，並記錄 `authorization_code_id`。透過現場任務短碼完成的任務，原因仍是 `task`，與掃描 QR Code 完成的紀錄相同。
- 重複兌換的防護靠記帳的 `dedupe_key`，授權碼是 `code:{授權碼 id}:{會員 id}`，現場任務是 `task:{任務 id}:{會員 id}`。
- 次數上限的檢查與記帳在同一個資料庫交易內，並鎖定該授權碼，避免多人同時兌換時超過上限。
