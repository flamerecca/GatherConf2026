## **為什麼要舉辦共聚年會**

### **一句話說明**

技術社群越分越細，彼此之間的牆也越來越高。共聚年會想做的事很單純：把牆打開，讓不同社群的人坐在同一個空間裡，真正聊上幾句話。

### **我們看到的問題**

隨著技術的轉變，以及人工智慧的突破，我們在各個技術社群的活動中，發現了大家共同的擔憂和困境：

- **社群各自深耕，彼此很少交流**：開源社群、商業技術社群、企業方案社群，各有各的聚會、語言與關注焦點，很少有機會同場交流。
- **同溫層讓視野變窄**：一直待在技術社群裡，聽到的永遠是相似的觀點。許多有趣的點子和做法，其實就藏在隔壁領域，只是沒有人把兩邊連起來。
- **社群主辦人經常孤軍奮戰**：每個社群的主辦人都在面對相似的挑戰，像是找講者、找場地、找贊助、留住志工，卻很少有機會互相討論交流。
- **技術與實際應用之間有落差**：使用 AI 進行開發的創作者、傳統工程師與企業端的使用者，常常各說各話，缺少面對面討論的場合。

### **我們想改變什麼**

我們希望共聚年會成為一個開放、包容且充滿活力的跨領域 IT 交流空間，達成三件事：

1. **打破隔閡**：讓不同領域的社群在同一個屋簷下相遇。
2. **激發新想法**：透過知識共享、創意碰撞與相互學習，讓跨領域的觀點彼此啟發。
3. **建立長期連結**：不只是聽完講座就散場，而是讓參與者帶著新的人脈與合作機會離開，並且一起成長為更團結的社群。

### **為什麼是這樣的形式**

| 設計 | 背後的考量 |
| :---- | :---- |
| **120-200 人的規模** | 夠小，讓每個人都有機會和不同的人說上話。又夠大，足以匯聚多元的社群。 |
| **一日雙軌，八場講題** | 用有限的議程呈現不同領域的內容，讓參與者能依興趣選擇，也有時間留給交流。 |
| **Open space unconf** | 議題由參與者自己提出與討論，讓交流不只停留在台上講、台下聽。 |
| **茶水與下午茶，不提供午餐** | 把預算放在讓大家停留、聊天的時段，午餐則讓參與者自由安排，也能結伴到附近交流。 |

### **誰會從中受益**

- **社群組織者**：認識其他社群的主辦人，交換辦活動的經驗與資源。
- **開發者**：接觸自己平常接觸不到的技術領域與實務做法。
- **產品建構者與技術創新者**：在不同領域的碰撞中，找到新的靈感與合作對象。
- **贊助商**：直接面對跨領域的技術社群，讓產品與方案被更多元的受眾看見。

### **我們的核心價值**

- **開放**：歡迎來自不同領域、不同背景的人。
- **包容**：尊重不同的觀點與經驗，並遵守共同的行為準則。
- **協作**：以 1 加 1 大於 2 的跨社群綜效為目標，而不是彼此競爭。

### **期待的樣子**

活動結束後，我們希望參與者能說出這樣的話：「我今天認識了一個原本不會遇到的領域，也認識了幾位之後會持續聯絡的人。」

如果共聚年會能讓一場對話發生，讓兩個社群開始合作，我們就達成了舉辦的目的。
